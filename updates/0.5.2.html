Draplet 0.5.2 Alpha

Uses a persistent application signing identity so future updates signed with the same certificate can retain macOS privacy permissions.

Upgrading from 0.5.0 or 0.5.1: these older builds used ad-hoc signatures. This signing transition can require authorizing Accessibility and Screen Recording again. The upgrade is offered for review and will not install silently.

After updating, open System Settings → Privacy & Security → Accessibility and authorize the current Draplet in Applications. If an enabled old entry does not apply, remove it and add the current app. Also check Screen & System Audio Recording, then quit and reopen Draplet if macOS requests it. Draplet captures no audio. Preferences and pinned icons are retained.

This remains an unnotarized Alpha. The application certificate is self-signed; it does not provide Developer ID verification or remove Gatekeeper approval on first launch. No certificate installation or trust-setting changes are needed on users’ Macs.

  • Retains the Sound/AirPods overlap fix from 0.5.1.
  • Release checks reject incompatible silent updates and preserve the review requirement for older installations across future versions.
