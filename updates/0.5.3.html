Draplet 0.5.3 Alpha

  • Skips unnecessary cover drawing and repeated presentation-policy updates while preserving fresh backgrounds.
  • Stops a moving curtain when Reduce Motion is enabled during the transition.
  • Waits for screen-capture shutdown on normal quit, including streams still starting or retiring after a cached frame.
  • Keeps shutdown responsive inside macOS's modal termination loop.
  • Allows an unchanged frame to retry after a transient image-conversion failure.

Existing animation styles and paces, pinned icons and preferences are retained.

Upgrading from 0.5.0 or 0.5.1: these older builds used ad-hoc signatures. The signing transition can require authorizing Accessibility and Screen Recording again. These older installations must review the upgrade before installation.

After updating, open System Settings → Privacy & Security → Accessibility and authorize the current Draplet in Applications. If an enabled old entry does not apply, remove it and add the current app. Also check Screen & System Audio Recording, then quit and reopen Draplet if macOS requests it. Draplet captures no audio. Preferences and pinned icons do not need resetting.

This release retains the persistent signing identity introduced in 0.5.2. It remains an unnotarized Alpha with a self-signed application certificate, not Apple Developer ID distribution. First launch may require Open Anyway. No certificate installation or system trust changes are needed.
